CHANGES MADE TO THE WORK
(stated as required by section 4(b) of the Apache License, Version 2.0)

The model is converted to ONNX and shipped in that form. Two changes are made
during that conversion, both to the structure of the exported graph. No weight
value is altered, added or removed, and the vectors this model produces are
numerically identical to the original's (verified at cosine 1.000000 against
the reference PyTorch model on every export — see tool/export_model.py):

  1. The exported graph emits the CLS token, shape [1, 384], rather than the
     full final hidden state, shape [1, 257, 384]. This application uses only
     the CLS token; pooling inside the graph avoids transferring the remaining
     98,304 values out of the model on every inference.

  2. The exported graph's input is fixed at [1, 3, 224, 224] rather than being
     left symbolic in all four dimensions. This application feeds exactly one
     input size.

The conversion is performed by tool/export_model.py in this repository, which
is the authoritative description of what was done.
